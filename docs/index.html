NGS Variant Calling Pipeline

An end-to-end, reproducible short-read variant-calling workflow using real trio exome data for an osteopetrosis case study.

Reference: hg19/GRCh37 chromosome 8
Samples: father, mother, and proband
Workflow: download → QC → trimming → alignment → BAM processing → variant calling → filtering and annotation

Pipeline steps

  1. 01_download_data.sh — download FASTQ files and the chromosome 8 reference.
  2. 02_qc.sh — generate FastQC reports.
  3. 03_trim.sh — trim low-quality read ends with BBDuk.
  4. 04_align.sh — align reads with BWA-MEM.
  5. 05_process_bam.sh — sort, mark duplicates, and index BAM files.
  6. 06_call_variants.sh — call variants with bcftools.
  7. 07_filter_annotate.sh — filter candidates and optionally annotate them with VEP.

Run the workflow

Install the pinned Conda environment, activate it, then run the numbered scripts from the project root:

conda env create -f environment.yml
conda activate ngs-variant-calling
for script in scripts/0*.sh; do bash "$script"; done
